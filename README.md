# AnkiByMe

Надоело руками копировать карточки из чата в Anki, поэтому написал скрипт: кидаю слова в файл, он сам генерит карточку через Gemini и добавляет её в колоду.

Карточка такая: спереди перевод и предложение с пропуском, сзади слово, транскрипция, формы, коллокации, синонимы, примеры.

## Что нужно

- Python 3.10+, ставить ничего не надо
- Anki с аддоном AnkiConnect, Anki должен быть открыт
- ключ Gemini API (бесплатного хватает) в переменной `GEMINI_API_KEY`

## Как пользоваться

Создать рядом `words.txt`, по одной строке на карточку:

```
thrive
by and large
charge | The battery takes two hours to charge.
charge (обвинение)
```

После `|` можно дать своё предложение, в скобках нужное значение, если слово многозначное.

```
python anki_cards.py
```

`--dry-run` просто покажет карточки и ничего не добавит.

Готовые слова уезжают в `words_done.txt`. Колода и тип заметки меняются в начале `anki_cards.py`.
